## Captain's Log

<img align="left" src="https://raw.githubusercontent.com/alex-404-png/alex-404-png/main/assets/compass-illustration.svg" width="150" alt="Minimal line-art illustration of a compass" hspace="20"/>

I'm **Alex Sonavane**, a developer based in India who treats every empty repository like unmapped water — worth entering carefully, and worth exploring fully.

My work spans full-stack web development, game development, and open-source civic tech. I'm especially drawn to AI integration and the craft of building things that are self-contained and thoughtfully designed — whether that's a procedurally generated game world or a production-grade PWA. Continuous learning isn't a slogan for me; it's just how the work gets done.

**Right now:** building `SatyaSetu` (सत्यसेतु), an offline-first, privacy-respecting news platform for the Indian public interest — architected in full before a single page was built, and now being implemented file by file.
